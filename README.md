# Seek

Buscador de arquivos para Windows 10/11 (64 bits). Feito para achar arquivo perdido em disco cheio, de forma instantânea.

**[Baixar o Seek.exe (última versão)](https://github.com/inflzzz/seek/releases/latest/download/Seek.exe)**

Não precisa instalar: baixe e abra. O programa se atualiza sozinho quando sai versão nova.

## O que ele faz

- Busca em milissegundos em milhões de arquivos (nome, pasta, tipo, tamanho, data).
- Qualquer extensão: `.png`, `.exe`, `.xyz`... Categorias: `foto`, `vídeo`, `app`, `código`, `design`, `dados`.
- Miniaturas de fotos, ícones dos aplicativos e vistas Lista, Pequena, Média e Grande.
- **Ctrl + Espaço** abre uma janelinha de busca de qualquer lugar; fica na bandeja do Windows como o Everything.
- Acompanha o disco ao vivo e lê o disco inteiro em segundos (como administrador, em disco NTFS).
- Busca por semelhança: nome parecido, foto parecida, ícone parecido.
- Tudo roda no seu computador. Nada é enviado para a internet, a não ser a consulta de versão nova deste repositório.

## Primeira vez

O Windows pode mostrar "app desconhecido" (SmartScreen), porque o programa não é assinado: clique em **Mais informações → Executar assim mesmo**.
Depois clique em **Escolher disco**.

Veja as [versões publicadas](https://github.com/inflzzz/seek/releases) para as novidades de cada uma.
